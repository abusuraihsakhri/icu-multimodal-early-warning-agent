ICU early-warning threshold demonstrator

Browser-only educational implementation of the three threshold checks in the Python repository.

Not for patient care. This software does not process waveforms or laboratory time series, predict deterioration, or provide clinically validated risk estimates. Use synthetic, non-identifying examples only.

Example input

Never enter patient names, MRNs or other personal information.
Threshold: greater than 25.
Threshold: greater than 12.
Flag words: DISCORDANT, ANOMALY, MUTANT, VIOLATION, FAIL, REJECT.

Local result

Select Evaluate example to run the checks.

No API requests, external assets, HMAC signing, or browser storage are used. Classifications are non-clinical demonstrations. The Python REST API requires separate server hosting.
